Leftover hub links at the point of use

UX recommendation for the Product Security Center leftover box. CVE database and Security advisories move to the masthead. This file shows where the other six links live. Not a live portal change.

The change in one sentence Retire the two-column box. Put each leftover link where people already do that job: bulletins on Security updates, severity next to the Severity column, story and process on Vulnerability management, data and labs in tools and learn.

What happens to the leftover box

Today the box lists eight destinations under Security updates and Vulnerabilities. After the masthead owns two of them, the remaining six are not one family. Do not keep a thinner version of the same box. Do not reuse those two headings on the Center. They now belong to the masthead.

Security updates owns the bulletin index

Advisories are the full RHSA catalog. Bulletins are a separate list of RHSB documents. The Bulletins tab is not a filter that hides advisory rows. One bulletin can point at several CVEs and several advisories. A bulletin can exist while fixes are still rolling out.
