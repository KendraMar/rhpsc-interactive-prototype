Red Hat Security Advisories

Security advisories (RHSA) are the published write-ups for security fixes. This is not the full errata catalog. Bug-fix and enhancement errata live under Errata.

AdvisorySynopsisSeverityProductsIssued

A bulletin (RHSB) is a separate write-up for a smaller set of cases that need more context. It is not a filter on the advisory table. Each bulletin then points at CVEs and at the advisories that describe the patches.

BulletinImpactStatusPublic date

Red Hat Product Errata

Errata are the packaged releases. Type can be Security (RHSA), Bug Fix (RHBA), or Enhancement (RHEA). A security advisory is only the RHSA write-up. Come here when you need the update you apply, including non-security errata.

Product Security Center / Get the data / Product Security MCP

Product Security MCP

Skip this website. Connect a Model Context Protocol client and query the same CVE, advisory, and errata records the GUI shows.

This is an alternative to searching the CVE database, Security Advisories, and Errata in the browser. It is not a replacement for Hybrid Cloud Console, which is about your registered systems.

What a client can ask

  • Find a CVE and its Red Hat severity
  • List security advisories for a product
  • Return the related errata you apply
  • Point to a bulletin when a CVE is covered by one

What it will not do

  • It will not disclose embargoed issues
  • It will not replace secalert reporting
  • It will not replace scanner feeds. Those stay on For scanners and APIs

Product Security Center / Understanding severity ratings

Understanding severity ratings

Red Hat rates issues on a four-point scale: Low, Moderate, Important, and Critical. CVSS is extra guidance. Red Hat does not use CVSS alone to set this rating.

Live destination: access.redhat.com/security/updates/classification
